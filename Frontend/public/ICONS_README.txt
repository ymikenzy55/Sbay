PWA ICONS NEEDED
================

You need to create two PNG versions of your sBay logo:

1. logo-192.png (192x192 pixels)
2. logo-512.png (512x512 pixels)

HOW TO CREATE:
--------------
1. Open your Sbay.jpg logo in an image editor (Photoshop, GIMP, Canva, etc.)
2. Resize to 192x192 pixels, export as PNG → save as "logo-192.png"
3. Resize to 512x512 pixels, export as PNG → save as "logo-512.png"
4. Place both files in this folder (d:\Sbay\Frontend\public\)

ONLINE TOOLS (if you don't have image editor):
----------------------------------------------
- https://www.iloveimg.com/resize-image
- https://www.canva.com (free)
- https://www.photopea.com (free Photoshop alternative)
